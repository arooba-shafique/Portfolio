# Portfolio Website

My personal portfolio website built with React and Tailwind CSS.

## Features

- Responsive design
- Project showcase
- Clean and modern UI

## Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS, shadcn/ui
- **Build Tool:** Vite
- **Routing:** wouter

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/arooba-shafique/Portfolio.git
   cd Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```
